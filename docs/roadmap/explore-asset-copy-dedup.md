# 엔진 개선 과제: 탐색 라운드 자산 사본 중복(`explore-asset sync`) (2026-11-20)

상태: **과제 기록(구현 전)**. 엔진 코드, 기존 라운드의 `_assets/`, Git 이력은 바꾸지 않았습니다.
근거: 검증 프로젝트(SMAPSH, `badminton-playbook`)의 시각 탐색 V02–V08. 프로젝트 사례는 재현 근거로만 쓰고, 해결 방향은 프로젝트와 무관하게 적습니다.

## 1. 현상

`explore-asset sync --round <R>`([pd_assets.py](../../skills/product-design/scripts/pd_assets.py) `act == "sync"`)는 라운드의 `_assets/`를 지우고 **자산 등록부의 모든 자산**을 복사합니다. 시안이 실제로 참조하는지와 관계가 없습니다. 사본은 등록부 원본(`design-profile/assets/`)과 바이트가 같습니다.

| 라운드 | 사본 수 | 용량 | Git |
|---|---|---|---|
| V02–V05 | 16·26·46·56 | 합계 약 2.2MB | 이미 커밋됨 |
| V06·V07·V08 | 78·78·79 | 14·14·16MB | 미추적(커밋하면 약 44MB) |

- V08-A가 실제로 쓰는 자산은 13개(약 2.1MB)뿐입니다. 등록부에 큰 PNG(경기장·선수·배너, 0.5–1.7MB)가 쌓이면서 라운드마다 약 14–16MB가 늘어납니다.
- 같은 자산이 라운드 수만큼 중복되므로 증가량은 대략 (등록부 용량) × (라운드 수)입니다.

## 2. 사본이 필요한 이유(바꿀 때 지켜야 할 계약)

- 시안은 라운드 사본(`../_assets/AST-nnn.*`)만 참조합니다. 등록되지 않은 이미지·인라인 SVG를 막는 검사(`asset_unregistered`·`asset_inline_svg`)가 이 경로 규칙에 기대고 있습니다.
- `explore-verify --asset-fallback`은 `*/_assets/*` 요청을 막아 자산 없이 렌더를 측정합니다.
- 선택 이후 보존 집합 불변 규칙과 구현 보호(`pd_guard`의 탐색 산출물 색인·`explore_copy`)는 `design-explore/` 전체를 봅니다. 사본은 등록 자산과 같은 해시라 공식 자산으로 판정됩니다(`pd_guard` 313행 주석).

## 3. 권장 방향: 실제 참조 자산만 복사

`sync`가 라운드 시안들의 참조를 읽어 그 자산만 복사합니다.

1. 참조 수집: 각 시안의 HTML `data-asset="AST-nnn"`과 CSS·HTML의 `url(../_assets/AST-nnn.*)`(주석 제외 — 15절 주석 판정과 같은 규칙).
2. 시안이 아직 없거나 참조가 0이면 지금처럼 전체를 복사하거나(하위 호환), `--all` 옵션으로만 전체 복사.
3. 시안 수정 후 새 자산을 쓰면 `explore-check`가 `asset_unregistered`가 아니라 "sync 필요(`asset_not_synced`)"로 안내하고, `sync`를 다시 실행하면 추가됩니다.
4. `sync`는 지운 사본 목록을 출력합니다(조용히 지우지 않음).

기대 효과(SMAPSH V08 기준): 79개 16MB → 13개 약 2.1MB. 검사·측정·보존 규칙은 그대로입니다.

## 4. 함께 검토할 선택지

| 안 | 내용 | 장점 | 비용 |
|---|---|---|---|
| A(권장) | 참조 자산만 복사 | 계약 변경 없음, 효과 큼 | 참조 수집 코드·테스트 |
| B | 선택되지 않은 라운드의 `_assets/`를 Git 제외(`keep_unselected` 규칙과 같은 방식) | 저장소 증가 차단 | 미선택 시안을 다른 환경에서 열 때 `sync` 다시 실행 필요 |
| C | 사본 대신 등록부 파일 직접 참조 | 사본 0 | 시안 경로 규칙·`pd_guard`·fallback 측정 패턴까지 바뀌는 계약 변경 |
| D | 하드 링크·심볼릭 링크 | 디스크 절약 | Git·OS별 동작 차이, 보존 해시 의미 모호 |

A와 B는 함께 쓸 수 있습니다.

## 5. 범위 밖(이번에 하지 않음)

- 이미 커밋된 V02–V05 사본의 추적 해제, 기존 라운드 사본 정리 — 사용자 결정과 dry-run 절차가 필요합니다(`docs/policies/artifact-retention.md` §5).
- 테스트: 구현 시 `tests/`에 참조 수집(주석·data-asset·CSS url), 하위 호환(참조 0), 보존 집합 불변, fallback 측정 경로 회귀를 추가합니다.
