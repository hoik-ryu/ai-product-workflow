# `/product-build` 테스트 시나리오와 실행 기록

## 실행

```bash
python3 tests/product_build_test.py                                  # 자체 완결형(가상 제품 2종 + L1·기획 미승인)
python3 tests/product_build_smapsh_check.py <SMAPSH 복제본 경로>        # 실제 프로젝트 복제본(원본 경로는 거부)
python3 tests/product_build_exec_test.py                             # M2.2 배치 실행(자체 완결형)
python3 tests/product_build_smapsh_exec_check.py <SMAPSH 복제본 경로>   # M2.2 실행을 실제 프로젝트 복제본에서(새 복제본 사용)
tests/harness/product_build/run_regression.sh [작업 폴더]               # 실제 Claude 대화 검증 P1–P5(claude -p, 약 10–15분)
```

복제본 예: `rsync -a --exclude node_modules --exclude dist --exclude .venv --exclude .env --exclude experiments <원본>/ <임시>/smapsh/`.
복제본은 실행 후 지웁니다. `.env`는 복사하지 않습니다.
